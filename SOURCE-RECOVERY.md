# Sunshade source recovery

This repository restores the original source base from haines-forms at immutable commit 52216f8f5d9127151bf37df6c6dd02bc3e506b0d, tree 2ab49805302ae14fe33ea0ee4e9d28d2f0568d25. Source file integrity was verified against Git blob hashes; SHA-256 hashes are recorded in RECOVERED-SOURCE-MANIFEST.json.

Environment/credential files and automation configuration are excluded. No packages were installed, application code executed, migrations run, providers called, CI configured or deployment performed.

This is the earlier source base, not the previously accepted local candidate. Later form UI, regression tests, screenshots and maker/checker receipts could not be recovered from the available repository history or searched local exports. Previous test passes do not apply to this recovered tree.

The recovery branch preserves the available foundation for continuing work without inventing a verified snapshot. Existing source repositories and their open PRs were not changed.
